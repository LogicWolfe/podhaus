Networking

Docker bridge networking, Numbat's Pomerium and rathole edge, Caddy origin separation, and Terraform-managed DNS.

dockernet bridge

Every UI-facing container joins an external bridge network called dockernet at 172.18.0.0/16. Within the bridge, containers reach each other by container name via Docker's embedded DNS — never by static IP. Static IPs are reserved for LAN devices (e.g. the UniFi gateway at 10.0.0.1) and host-network services.

Each consumer compose file declares: 

networks:
  - dockernet

# at the bottom:
networks:
  dockernet:
    external: true

Host-network services

A few services need direct host network access:

  • Home Assistant — Bluetooth, mDNS, multicast device discovery.
  • Plex — Plex's own LAN discovery protocol, GDM/DLNA.
  • Syncthing (kangaroo-side) — LAN device discovery via UDP/21027 multicast.

These declare network_mode: host in their compose. Caddy reaches them via the dockernet bridge gateway IP 172.18.0.1, such as home.pod.haus → 172.18.0.1:8123.

Numbat edge

Numbat is the active public gateway. Bilby and other internal targets make named outbound rathole connections to it; Numbat has no routed path into the home network.

Protected browser names resolve to the application address. Pomerium authenticates with Pocket ID, then reaches Caddy's private :4443 listener through a loopback-only rathole service. That listener also requires Pomerium's client certificate. The public rathole service reaches Caddy :4444, which has no protected virtual hosts.

The public listener serves MinIO S3, Pocket ID, UniFi, static sites, scoped Umami ingestion, paperless-api.pod.haus, Komodo's outbound connection, and mTLS log ingestion. Forgejo uses Pomerium for HTTPS and the application address on port 22 for ordinary git@git.pod.haus SSH. Host SSH uses Pomerium on ssh.pod.haus:22; routes are named bilby, numbat, and voltaire. The generic pomerium-ssh-origin-bootstrap installs the machine-local outbound relay and CA trust on a target; the operator chooses the initial SSH transport separately.

Identity and machine exceptions

Pomerium's default policy allows the two family Pocket ID identities. Syncthing and the development service are Nathan-only. Exact public exceptions exist for Forgejo LFS, Komodo's GitHub webhook, HyperDX MCP, and the separate Paperless API hostname. HyperDX and Paperless each require a distinct X-Podhaus-Gateway-Token from the Pomerium Gateway Tokens 1Password item, followed by the application's own credential.

Cloudflare scope and rollback

Cloudflare remains authoritative DNS and the CDN for public websites and their Umami ingestion paths. CDN zones use Full (Strict) origin TLS to Caddy. Protected services and raw protocols are DNS-only. Cloudflare Tunnel, Access, Kookaburra, and the Kookaburra Tailscale management path remain running as rollback infrastructure until Nathan independently verifies Numbat. Their resources are still Terraform-owned; migrated DNS no longer points at them.

Management and logs

Numbat Periphery dials wss://core-connect.pod.haus through the public TLS relay; Komodo's Noise keys authenticate it. Numbat Alloy sends OTLP to https://logs-ingest.pod.haus; Caddy requires Numbat's client certificate and ClickStack requires its ingestion key. Neither path uses Tailscale or exposes an internal management listener.

DNS

All DNS is Terraform-managed under terraform/, state in MinIO at s3://terraform-state/podhaus.tfstate:

  • Cloudflare public zones: DNS-only A records to Numbat for protected and raw services; proxied A records to Numbat's relay address for the public CDN sites. The old Tunnel CNAME targets remain available for rollback.
  • UniFi LAN-side split-horizon. Both unifi.pod.haus and bilby.pod.haus resolve to bilby at 10.0.0.119. The former goes through Caddy so the Terraform provider sees the same valid hostname certificate on and off LAN.

Workflow: edit the relevant dns_<zone>.tf, run terraform plan from terraform/, then terraform apply (stock terraform, no wrapper, from any machine; creds are loaded by the PWD-scoped chezmoi fish hook through op inject). The S3 state backend is the public https://storage.pod.haus (Caddy → MinIO), not Cloudflare-proxied — see Terraform.

Provider docs (read before editing): cloudflare_dns_record, unifi_dns_record.
