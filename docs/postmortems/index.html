Postmortems

Incident records. One file per incident, written when something user-visible broke or a near-miss surfaced a latent defect.

Conventions for writing one are in conventions.md. Action items live in each postmortem's Resolution section as checkboxes; they get flipped to done in-place with a date as they land, rather than spawning follow-up postmortems.

Writing a new postmortem

  1. Create docs/postmortems/YYYY-MM-DD-<short-slug>.md using the conventions doc as a template.
  2. Add a row to the table above.
  3. Add a one-line entry under the Postmortems section in AGENTS.md — that's what every contributor / agent sees in the root instruction file on every conversation.
  4. If the postmortem produces a new convention or hard rule, land that in the appropriate doc (stack-conventions.html, hard-rules section of AGENTS.md, etc.) and link back from the postmortem.
