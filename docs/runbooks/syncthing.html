Syncthing

Kangaroo is the authoritative source for Pinelake's one-way media mirror. Four narrowly rooted folders expose only Movies, TV, Kids, and Sports; Kangaroo is send-only and Pinelake is receive-only. Other Kangaroo folders and peers are independent of this relationship.

Pinelake never sends moves, deletions, conflicts, or newly discovered files back to Pouch. Its fresh identity and database live at /Users/Shared/Podhaus/syncthing. Kangaroo keeps its established identity and database at /share/CACHEDEV2_DATA/Container/syncthing-config because that state also owns unrelated folders and peers.

Source selection

Each Kangaroo source root contains its own ordinary .stignore. There is no include helper and no ignore file on Pinelake. Syncthing does not transfer its special ignore file; the receiver gets only the paths the source advertises.

Each file has three ordered slices: permanent junk exclusions, exact rooted negated paths for selected media, and a final ** that denies all other content. First-match precedence ensures release metadata, archives, partial downloads, and operating-system metadata remain excluded even inside an allowed directory. Artwork and subtitle files are not blanket excluded because Plex can use them.

Edit the normal file through the folder's Edit Ignores control in Syncthing. Flood's Bilby instance also runs flood/scripts/pinelake-stignore.py: a completed torrent carrying the pinelake tag contributes its exact published path to the matching source file. The reconciler validates all four files before an atomic, insert-only write. Removing a tag does not remove media or its allow-list entry.

Containers and networking

Both containers use host networking so Syncthing's Transmission Control Protocol listener and User Datagram Protocol discovery work normally. Kangaroo's stack is syncthing/; Pinelake's is pinelake/syncthing/. The Pinelake pre-deploy gate proves the exact TerraMaster volume and all four destination roots before Komodo can replace the container.

The administration interfaces bind to port 8384 without Syncthing-local credentials. Pomerium is the external authentication boundary and the trusted local networks retain direct access. Set gui.insecureAdminAccess=true through Syncthing's configuration application programming interface to suppress its open-interface warning; that setting changes the warning, not access control.

Safe changes

  • Keep Kangaroo send-only and Pinelake receive-only for all four folders.
  • Never reuse Pinelake's retired identity or database in the managed container.
  • Before enabling a new selection, confirm only its exact negated path was added and the other three files are unchanged.
  • Verify permanent junk remains absent while media, artwork, and subtitles arrive.
  • Treat an unexpected Pinelake local addition as receive-only override state; do not use it to update Pouch.

Recovery state

Backrest captures both endpoints' configuration and identity state. Restore a configuration directory only as a complete unit: certificate, key, configuration, and index database must remain consistent. Pouch media is valuable bulk storage and is not reconstructed from Pinelake.
