The logs contain no file names or error messages for these requests, so they cannot establish whether all three failures were the same release or why that file was rejected.

Flood's completion pass can only label a movie after Plex has indexed its file. Here Plex created the movie six seconds after completion triggered the hook, and no label application was logged until the scheduled 07:00 pass. The indexing race explains the window when Rowan's label-filtered account could not find the movie; the manual Plex edit closed it first. A read-only query using Rowan's own Plex access now finds it in Kids Movies.

Why the Indigo label was wrong

The 07:00 sync logged labeled movie 'Harry and the Hendersons' += Indig,rowan. It copied Flood's torrent tags, including Indig without the final o; the logs do not show how that spelling was entered. Its rowan message is misleading in this case: your 06:58 edit had already supplied Rowan's label. The script compares label spelling with exact case, so it treated lowercase rowan as missing beside Plex's existing Rowan. An earlier sync recorded Rowa for another title, so a truncated tag has appeared before.

Flood torrent: Indig, rowan → Plex movie now: Indigo, Indig, Rowan

Your manual Plex edit supplied the intended Indigo and Rowan labels before the scheduled sync. The later sync left a stray Indig label, and the 1080p torrent still has that misspelled Flood tag. The 2160p torrent is accepted but incomplete; its current publish destination is /data/Kids/TV, which is also worth correcting for a movie.
