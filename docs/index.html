Home server infrastructure

podhaus docs

Docker infrastructure for bilby (primary), kangaroo (QNAP storage and secondary services), and Numbat (active Perth gateway), with Kookaburra retained for rollback. One Komodo Core manages the fleet; secrets come from 1Password and external infrastructure lives in Terraform.

Start here

New to the repo or returning after a while? Read these four in order to get oriented in about ten minutes:

  1. Architecture — the big picture, in one page.
  2. Hosts: what runs on bilby, kangaroo, Numbat, and Kookaburra.
  3. Komodo — how the orchestrator works, two operating models.
  4. Stack conventions — how to add or change a service.

Conventions used in these docs

Tip Short, actionable hint or pointer to deeper material.
Note Context that's not strictly required but useful when investigating an issue.
Watch out A known sharp edge — usually a documented workaround for an upstream bug or environment quirk.
Caution Destructive or hard-to-reverse operation. Read twice, type once.

Contributing

Every page is a static HTML file. Edit it, save, refresh the browser — changes appear immediately, no rebuild or container restart. Add a new page by copying docs/_template.html and appending an entry to docs/assets/nav.json. Plans can be authored as .md or .html; both render via the plans index.

AI agents working in this repo should read Architecture, Komodo, and Stack conventions before making changes — those three pages plus the relevant runbook cover most edits. Project instructions live in AGENTS.md at repo root (Claude Code imports it via CLAUDE.md).
