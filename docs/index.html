Home server infrastructure

podhaus docs

Docker infrastructure for bilby (primary), kangaroo (QNAP storage and secondary services), and Numbat (active Perth gateway), and fractal (outbound-only remote host). One Komodo Core manages the fleet; secrets come from 1Password and external infrastructure lives in Terraform.

Start here

New to the repo or returning after a while? Read these four in order to get oriented in about ten minutes:

  1. Architecture — the big picture, in one page.
  2. Hosts: what runs on bilby, kangaroo, Numbat, and fractal.
  3. Komodo — how the orchestrator works, two operating models.
  4. Stack conventions — how to add or change a service.

Conventions used in these docs

Callouts

Use a blockquote with a short bold title for notes, sharp edges, and destructive-operation warnings. Keep the title specific rather than encoding a presentation-only callout type.

Contributing

Markdown is preferred for new pages; use an HTML fragment only when its layout carries useful meaning. Edit, save, and refresh — changes appear without a build or restart. Navigation follows the filesystem automatically; use a directory's _nav.toml only when it needs an explicit label or ordering. The complete conventions are in the central authoring guide.

AI agents working in this repo should read Architecture, Komodo, and Stack conventions before making changes — those three pages plus the relevant runbook cover most edits. Project instructions live in AGENTS.md at repo root (Claude Code imports it via CLAUDE.md).
