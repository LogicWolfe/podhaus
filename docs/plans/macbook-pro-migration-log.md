# MacBook Pro migration log

A running record of the effort to move Nathan's laptop role from `nb-macbook-air`
to `nb-macbook-pro`, kept to distil better configuration and a smoother
bootstrap for the next development laptop. Each entry records what was done,
what got in the way, and the improvement it suggests. The companion plan is
[macbook-pro-migration.md](macbook-pro-migration.md). When the migration ends,
the improvements below become changes to the dotfiles, Podhaus and
[MacBook setup](../macbook-setup.md), and this log is deleted.

Entry shape: date, step, what happened, friction, improvement candidate.
